| 位置                      | 一句话职责         | 判定它是否越界的判据                  |
| ----------------------- | ------------- | --------------------------- |
| `main.py`               | 装配层，所有零件进行装配成一个整体  | 是否有业务逻辑 |
| `config.py`             | 环境变量的总体调配    | 代码里出现字面量（IP、key、URL）        |
| `.env` / `.env.example` | 运行环境，确定进库配置 | 不出现密钥 |
| `api/health.py`         | 健康检查的两个端点，配合对应故障动作   | 两个端点查的是同一批东西                |
| `core/errors.py`        | 错误代码配置，为整体服务错误负责      | 只在 errors 里配置错误信息              |
| `tests/`                | 测试，锁住契约     | 测试文件只在 tests/里           |
